# Essay / Writing Format Audit — BM, 华文, English — 2026-07-14

Audit of how essay questions are generated for the three language subjects and whether
they align with **SPM requirements** and provide real **essay-writing support**. Grounded
in the code paths, not assumptions.

## How essay questions are actually structured

Every essay flows through **one generic prompt** (`agents/orchestrator.py:1485-1514`,
mirrored in `agents/quiz_agent.py:50-81`). A per-topic *hint* string from
`_subject_topic_hint()` (`agents/orchestrator.py:383-590`) is appended to nudge
language-specific format.

The generic prompt is **science/humanities-shaped**:
- forces a `"Based on the following information:"` stimulus → *"Explain/Discuss"* task
- `model_answer` of **150–200 words**
- marks split content + communication, `max_marks: 10`
- bands A(8-10) / B(5-7) / C(1-4)

| Language | Writing hint? | What the hint says | SPM alignment |
|---|---|---|---|
| **Malay** (SPM 1103) | ✅ `orchestrator.py:390` | Karangan type (rencana/surat/pidato…), tajuk, bahan rangsangan, 3 isi pokok, min **350 patah perkataan** | ⚠️ Partial (~6/10) |
| **Mandarin** (华文) | ✅ `orchestrator.py:428` | 题目 + 3 提示, min **500 characters** | ⚠️ Partial (~5/10) |
| **English** (SPM 1119) | ❌ **none** | falls through to Reading-Comprehension fallback (`:524`) or generic essay | ❌ Misaligned (~2/10) |

## Key problems

### 1. English has no writing support at all
The English topic list (`orchestrator.py:864-872`) is *thematic comprehension + Literature
+ Grammar + Vocabulary* — there is **no "Continuous Writing" / "Directed Writing" topic**.
If essay mode triggers on a thematic topic, the hint tells the model to *"write a reading
comprehension passage + inference question"* (`:524-531`) — the opposite of an essay. Maps
to `SPM_FORMAT_GUIDE.md:289` ("Directed Writing… still missing"). Real SPM Paper 1 writing
is ~35 marks / 3 parts; currently **0% covered**.

### 2. The generic prompt fights the language hints
Even where BM/华文 hints exist, the base prompt still injects:
- `"Based on the following information:"` stimulus — **wrong for language composition**. A BM
  *karangan* / 华文 *作文* is a free/guided composition on a title, not a stimulus-explain task.
- `model_answer` "150–200 words" — but the hint demands **350 words (BM)** / **500 chars
  (华文)**. The exemplar shown to the student is ~half the required length.
- `max_marks: 10` — SPM BM Bahagian B and 华文 命题作文 are worth far more; 10 is not a real
  allocation.

### 3. Marking is content-first — wrong weighting for language essays
The essay evaluator (`orchestrator.py:1727-1753`) uses generic bands + error categories
(Conceptual Gap / Structural Issue / Language Barrier / Insufficient Depth). For a
*language* paper, marks are ~half **bahasa** (grammar, vocabulary range, cohesion) and half
**isi/pengolahan** — the current rubric under-weights mechanics and gives no
writing-specific feedback (paragraphing, genre conventions, register).

### 4. Structural omissions vs real SPM
- **BM** missing **Bahagian A** (guided writing from a visual stimulus); the karangan hint
  also wrongly attaches a *bahan rangsangan* to the open-response Bahagian B. Type list
  incomplete (no laporan, cerpen, ulasan).
- **华文** missing **应用文** (functional writing: 书信 / 报告 / 通告) — only 命题作文 is covered.

## Bottom line
- **Malay: ~6/10** — closest to correct, but generic-prompt conflicts (stimulus, length,
  marks) leak through.
- **Mandarin: ~5/10** — right idea, missing 应用文, same length/marks conflicts.
- **English: ~2/10** — no writing path exists; essays are actively misrouted.

**Root cause:** language composition is being generated by a content-essay prompt.

## Recommended fix
Add a dedicated `guided_writing` / `continuous_writing` question type (already flagged in
`SPM_FORMAT_GUIDE.md:289-290`) with:
1. its own prompt — title/theme + genre + guiding points, **no** stimulus-explain framing;
2. a **language-weighted rubric** (isi + bahasa + pengolahan) with realistic mark
   allocations and correct min length per language;
3. an English writing topic ("Continuous Writing", "Directed Writing") added to the topic
   list so English essays route correctly;
4. BM Bahagian A (guided writing) and 华文 应用文 sub-formats.

Lowest-effort first step: fix the length / stimulus / marks conflict bleeding from the
generic prompt into BM & 华文.
