# SEDA Coding Brief — one page (read before you start)

Thank you for coding. You are one of **two independent coders**. Please do **not**
discuss the items with the other coder until both of you have finished — the whole
point is a blind, independent second opinion so we can measure agreement.

## What you are coding

Each row in your workbook's **Coding** sheet is one **communicative act** (roughly one
sentence) taken from an AI-generated *teacher intervention script* — the short thing a
teacher would say / do with a student who keeps making the same mistake. Your job is to
label the **dominant dialogic function** of each act using the SEDA scheme.

The scripts mix **English and Bahasa Malaysia** (e.g. *"Cuba fikir…"*). Both count as
normal classroom talk — code them the same way as English acts.

## The rules (important)

1. **One code per row.** Pick the single best-fitting code.
2. **Code the dominant function** if an act seems to do two things.
3. **The units are fixed.** Do not split, merge, or re-write any act text.
4. Use **ND** only when *no* dialogic cluster (IRE–GD) fits (e.g. bare praise, greeting,
   pure logistics with no scaffolding).
5. Put anything you're unsure about in the **notes** column — it helps adjudication later.
6. **Work alone.** No peeking at the other coder's file.

## The codes (full definitions + examples are on the "Codebook" sheet)

| Code | Cluster | In one line |
|---|---|---|
| **IRE** | Invite elaboration or reasoning | Ask the student *why / how* or to expand. |
| **RE**  | Make reasoning explicit | Spell out the reasoning / the *because*. |
| **BI**  | Build on ideas | Extend or refine an existing idea. |
| **CO**  | Connect | Link to real life, another text, or prior learning. |
| **RD**  | Reflect on dialogue/activity | Comment on *how* the learning/task is going. |
| **EI**  | Express or invite ideas | Offer/ask for an idea or opinion (no justification needed). |
| **PC**  | Positioning & coordination | Agree / disagree / take a stance on a view. |
| **GD**  | Guide direction | Steer the task — instructions, next step, focusing. |
| **ND**  | Non-dialogic / other | None of the above. |

## How to code in the file

1. Open your workbook (`coder_A.xlsx` **or** `coder_B.xlsx` — whichever you were given).
2. Read the **Codebook** sheet once (definitions, decision rules, one example each).
3. Go to the **Coding** sheet. For each row, read `act_text`, then pick a value in the
   **`code`** column from the dropdown (IRE/RE/BI/CO/RD/EI/PC/GD/ND).
4. Leave `code` blank for nothing — but aim to code **every** row.
5. Add optional `notes`. **Do not edit any other column** (script_id, act_id, act_text…) —
   those are how the two files get realigned afterwards.
6. Save (keep the `.xlsx` format) and send the file back.

Rows are in a different random order in each coder's file — that's expected; the `act_id`
column links them back together, so just code top to bottom.

_Est. time: ~167 acts, roughly 45–75 minutes._
