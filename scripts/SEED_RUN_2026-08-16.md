### Failure breakdown

| Type | Count | Cause |
|---|---|---|
| `start_session` timeout/connection error | 10 | LLM provider throttling under 4-way concurrency |
| `start_session` HTTP 500 | 1 | Chemistry/Thermochemistry (first-seen topic, generation error) |
| `submit_answer` timeout/connection error | 6 | Same provider pressure mid-session |

All failures were transient. Affected students still have partial mastery data from their successful questions. Re-running `seed_students.py` is idempotent — existing accounts are reused, failed questions simply re-attempt.
